# FutureTrack – Career Guidance Platform

FutureTrack is a web-based career guidance platform designed to help users explore career opportunities, prepare for interviews, find job-related information, build resumes, and follow learning roadmaps.

## Features

- **Career Guidance:** Explore career paths and opportunities.
- **Job Information:** Access job-related information.
- **Interview Preparation:** Practice and prepare for interviews.
- **Resume Support:** Access resume-related features.
- **Learning Roadmaps:** Follow roadmaps to support skill development.
- **Login System:** Provides login-related functionality.
- **Success Stories:** Displays success-story images.

## Technologies Used

- **Frontend:** HTML, CSS, JavaScript
- **Backend:** PHP
- **Local Development Server:** XAMPP

## How to Run the Project

1. Install and open XAMPP.
2. Start Apache. If your project uses a database, start MySQL as well.
3. Place the project folder inside the `htdocs` directory.
4. Open your browser.
5. Visit:     `http://localhost/FutureTrack/`

## Purpose

The purpose of FutureTrack is to provide a simple platform that supports career exploration, job preparation, interview practice, and skill development.
